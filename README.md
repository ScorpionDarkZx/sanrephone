# Sanre Phone — atualizações

Repositório interno do **Grupo Sanre** com o manifesto de atualização (`update.json`) do softfone **Sanre Phone** (uso interno).

- O aplicativo consulta o `update.json` e baixa o instalador da aba **Releases**.
- O instalador é conferido por SHA-256 antes de ser executado.
- Uso restrito aos colaboradores do Grupo Sanre.
